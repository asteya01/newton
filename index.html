Introducing Newton

The command line finally speaks your language.

Type what you want in plain English. Press Tab. The exact shell command appears in your prompt, ready for you to review. It's a small change to your prompt that changes how much of the terminal you're willing to use.

AAsteyaFounder, Newton · November 20, 2026 · 7 min read

In short

  • You type a sentence, press Tab, and the command appears. Then you read it and press Enter. Tab never runs anything for you.
  • It works in zsh, bash and fish, with Claude, any OpenAI-compatible service, or Ollama for free and offline.
  • It is free, open source and MIT licensed, with no account and no telemetry.

Every developer has the same small ritual. You know what you want to do. You want to find the big files eating your disk, or stop whatever is squatting on port 3000, or pack a folder into an archive. You know it's one line in the terminal. You just can't remember which line.

So you open a browser. You search. You skim a forum thread from 2014, find an answer with a lot of upvotes, and copy it. You paste it, edit a path, and hope the flags mean what you think they mean. Five minutes later the task is done and the thread of what you were actually working on is gone.

We have all accepted this as the cost of living in a terminal. We shouldn't have to. That's why I built Newton.

What Newton does

Newton does one thing very well. You type what you want, the way you would say it to a colleague, and you press Tab. Your sentence is replaced by the command that does it.

Illustrative example · fish 
$ find every file over 100MB in my home folder   ← you type this, then press Tab
$ find ~ -type f -size +100M                        ← Newton writes this
  ❯ lists files larger than 100 MB under your home folder

That's the entire interaction. There is no new window, no chat panel, no copy and paste. The command lands in your prompt, exactly where it would have been if you had typed it yourself. Press Tab again and Newton cycles through other ways to do the same thing. Press Shift+Tab and your original words come back.

Nothing runs until you press Enter. The command is yours to read, change or throw away.

Why it works as one key

Plenty of tools let you talk to an AI about the command line. Most of them make you leave the place where you were working. You switch to a chat window, describe the problem, wait, read a paragraph, copy a code block, switch back, and paste.

Newton removes every one of those steps by living in the one place you already are. Tab is the key your shell already uses to complete things for you. Newton simply teaches it to complete intentions too. If you type a normal command, Tab completes it the way it always has. If you type a sentence, Newton takes over.

The old loop

Stop. Open a browser. Search. Skim. Copy. Switch back. Paste. Edit. Hope.

With Newton

Type a sentence. Press Tab. Read the command. Press Enter.

It sounds small. In practice it changes how much of the terminal you're willing to use. When asking costs one keystroke, you stop avoiding the commands you only half remember.

You stay in control

A tool that writes commands is only useful if you can trust it, and trust is mostly about what the tool refuses to do. So Newton is built around a few rules that never bend.

  • Tab never runs a command for you. The command sits in your prompt. You press Enter, or you don't.
  • It warns you about risk. If a command is destructive, such as deleting recursively, force-pushing, or throwing away uncommitted changes, Newton says so in plain words before you decide.
  • It protects your secrets. Obvious secrets such as keys and tokens are redacted before anything is sent to a model.
  • It has no account and no telemetry. There is nothing to sign up for and nothing phoning home.
Illustrative example · a command that deserves a second look 
$ git reset --hard
  ❯ resets your files to the last commit
  ▲ careful: Discards all uncommitted changes

Beyond one-liners

One-line commands are where Newton starts, not where it stops. The same idea scales up to the jobs that used to eat an afternoon.

Plan mode

Describe something bigger, such as set up a Python project with tests, and Newton gives you a checklist instead of a single command. You approve it one step at a time. You can skip a step, edit it, undo it, pause, and pick it up tomorrow. Before it starts, Newton checks that the programs the plan needs are actually installed. When it's done you can export the plan as a script or as Markdown, so the work is reusable.

Ask and chat

Pipe anything into newton ask and get an explanation back in the terminal. A failing test run is the classic case:

$ npm test 2>&1 | newton ask what broke

Fix

When a command fails, newton fix reads what just happened, explains the error in plain language, and proposes the repair. It's like having someone look over your shoulder who has seen this error before.

Commit

Stage your changes and run newton commit. It reads the diff and your recent commit history, then writes a message that matches how you already write them.

Iris, the agent

For bigger jobs you'd rather hand off, run newton agent. It opens Iris, a chat window in your browser that works on your own computer. Ask it what's using my disk space? and it runs the commands itself, reads the results, and tells you what it found. Looking around, like listing files or reading a git log, runs on its own. Anything that could change or delete something shows you the exact command and waits for your Allow or Deny. It never reads files like .env or SSH keys, and the app only answers to your own computer.

Your AI, your rules

Newton doesn't lock you into one model. You bring your own. Use Claude with your Anthropic key, any OpenAI-compatible service, or Ollama to run a model on your own computer.

That last option matters more than it sounds. With Ollama, Newton is completely free and works offline, and the words you type never leave your machine. A local model is slower than a hosted one, so the first answer can take a few seconds while the model loads. For a lot of people, trading a few seconds for total privacy and a zero-dollar bill is an easy choice.

Built to be trusted

I care a lot about whether a tool is boringly reliable, so Newton has a serious test suite: 133 automated tests. Some of them open real zsh, bash and fish sessions, type a sentence, press Tab, cycle the alternatives, undo, and check that normal completion is untouched. Plan mode has its own end-to-end suite that includes failures, retries, pausing and resuming.

Installation is a single script that needs only Python 3.9 or newer. It adds Newton to your path and turns on Tab for your shell. If something is off, newton doctor checks your setup and tells you what to fix. Uninstalling is one command, and it removes exactly what the installer added.

Who it's for

If you're new to the terminal, Newton is a gentle way in. You can say what you want and learn the command by reading it, which is how people have always learned shells, only faster.

If you live in the terminal, it removes the small speed bumps: the flag you never remember, the one-off awk you'd rather not write, the three minutes lost to a search.

If you run servers or build software, plan mode and newton fix turn long, fiddly tasks into things you can review one step at a time.

What Newton isn't

Newton is young, and I'd rather tell you that than pretend otherwise. It writes commands with the help of an AI model, and models make mistakes. That's why Tab never runs anything on its own, why Iris asks before it changes anything, and why I'd encourage you to read each command before you press Enter. Newton is meant to make you faster and better informed, not to replace your judgment.

It's also a small project. If it gets something wrong, or there's a shell, a platform or a workflow you want it to handle, tell me. That feedback is the most useful thing anyone can give it right now.

Try it in a minute.

You need Python 3.9 or newer and git. Open a new terminal when the installer finishes, type a sentence, and press Tab.

# get Newton
$ git clone https://github.com/asteya01/newton
$ cd newton
# install and run the guided setup
$ sh install.sh
