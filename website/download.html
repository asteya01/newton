Install in a minute.

Pick your system. After the download, it's the same three commands everywhere.

  1. Download newton.zip

    It lands in your Downloads folder.

  2. Open Terminal and run the installer

    macOS includes Python 3. If it's missing, macOS offers to install developer tools.

    cd ~/Downloads
unzip newton.zip
cd newton
sh install.sh

  3. Open a new terminal

    Type a sentence and press Tab. zsh, the macOS default, works best.

  1. Download newton.zip

    It lands in your Downloads folder.

  2. Unzip and run the installer

    Works on any distro with python3. If something is missing, the installer prints the exact command for your system.

    cd ~/Downloads
unzip newton.zip
cd newton
sh install.sh

  3. Open a new terminal

    zsh, bash 4+ and fish are supported.

  1. Turn on Linux

    Settings → About ChromeOS → Developers → Linux development environment → Turn on. Then open the Terminal app.

  2. Download newton.zip, then move it into Linux files

    In the Files app, drag newton.zip from My files › Downloads into Linux files. That folder is ~ in the terminal.

  3. Install what's missing, then Newton

    The first line is only needed if unzip or python3 isn't there yet.

    sudo apt update && sudo apt install -y unzip python3
cd ~
unzip newton.zip
cd newton
sh install.sh

  1. Set up WSL

    In PowerShell as administrator, install Ubuntu, restart, then open the Ubuntu app.

    wsl --install

  2. Download newton.zip, then install inside WSL

    Replace YOU with your Windows user name.

    cp /mnt/c/Users/YOU/Downloads/newton.zip ~
cd ~
sudo apt update && sudo apt install -y unzip python3
unzip newton.zip
cd newton
sh install.sh

  3. Use it inside WSL

    Newton runs in the Linux shell, not in PowerShell.

Check your download (optional)

The result should match the SHA-256 checksum at the top of this page.

macOS
shasum -a 256 ~/Downloads/newton.zip
Linux, Chromebook, WSL
sha256sum newton.zip

Update or remove it

newton update
newton uninstall

Download a newer zip, then run newton update. Updates are built and tested before they replace your copy. Uninstall only removes Newton's own lines from your shell config.

What you need.

Newton has no dependencies beyond Python.

A computer

macOS, Linux, a Chromebook with Linux turned on, or Windows with WSL.

Python 3.9 or newer

Already on most Macs and Linux systems. The installer checks and tells you what to do if it's missing.

A shell

zsh, bash 4 or newer, or fish. macOS ships bash 3.2, so use zsh, the macOS default.

An AI to talk to

Claude or any OpenAI-compatible service with your own key, or Ollama running on your own computer for free. Setup asks you which.

Release notes.

2.2.0

Installer and updates. One-file install into ~/.local/bin, a marked block in your shell config, newton update from a zip, folder or link, newton uninstall, and install checks in newton doctor. Chromebook is supported.

2.1

Plan mode, upgraded. Works better with small local models, preflight check for needed programs, undo, export as a script or Markdown, per-step timing, and a tab title and bell when a plan finishes.

2.0

Plan mode, ask, chat, fix and commit. Checklists you approve one step at a time, questions answered in the terminal, failed commands explained and fixed, and commit messages written from your staged changes.

1.0

Tab to command. Type a sentence, press Tab, get the command. Safety flags, secret redaction, and Claude, OpenAI-compatible and Ollama support for zsh, bash and fish.
