Quick start

Newton is one file that needs Python 3.9 or newer. No pip, no virtual environment, no admin rights.

cd ~/Downloads
unzip newton.zip
cd newton
sh install.sh

The installer puts newton in ~/.local/bin, makes sure that folder is on your PATH, then walks you through choosing an AI and turning on Tab. Open a new terminal when it finishes, type a sentence and press Tab.

Need system-specific steps (Chromebook, WSL)? See the download page.

Keys

KeyWhat it does
TabPlain English → command. On a normal command, ordinary completion.
Tab againCycle through alternative commands.
Shift+TabUndo: put your original words back.
Alt+NForce Newton on the current line, whatever it looks like.
# …Lines starting with # always go to Newton.

How Newton decides what's a sentence

A line goes to Newton if it starts with #, or if it has at least three words, no shell syntax and no flags, and either its first word isn't a real command or it reads like English. Anything else gets your normal Tab completion. To fire only on # lines, run newton config trigger prefix.

Plan mode

For anything bigger than one command, give Newton a goal. It drafts a checklist, then walks you through it. You stay in control of every step.

newton plan "deploy this app to a VPS"   # draft, review, run
newton plan --dry-run "…"                # just show the plan
newton plan -y "…"                       # auto-run safe steps (danger steps still ask)
newton status                            # the checklist for your active plan
newton plans [list|show|rm] [id]         # saved plans
newton resume                            # continue where you stopped
newton plans undo [id]                   # roll back finished steps, newest first
newton plans export [id] [-o FILE] [--md]  # a runnable script or markdown checklist

One key per step

⏎ runs it, e edits it, s skips it, ? explains it, a asks a question about it, r revises the plan, q pauses.

  • State carries over. cd and export in one step apply to the next.
  • Failures get fixed. Newton reads the error, proposes a fix and retries. You can run it, edit it, retry as-is, skip or ask.
  • Dangerous steps need a deliberate y. Even --yes only auto-runs safe steps.
  • Pause and resume. Press q or Ctrl+C and the plan is saved. newton resume continues from the same step.
  • Preflight check. Before anything runs, the plan lists the programs it needs with a ✓ or ✗ for what's installed.
  • Undo and export. newton plans undo reverses steps newest first and asks before each. newton plans export -o setup.sh makes a runnable script; --md gives a checklist.

Put $(newton prompt) in your prompt to keep the active plan visible.

Iris, the agent

Run newton agent to open Iris, a chat app in your browser that can look around your computer and do tasks step by step.

newton agent                     # open Iris in the current folder
newton agent --dir ~/projects     # start in another folder
newton agent --ask                # ask before every command
newton agent --no-open            # print the link instead of opening a browser
  • Read-only steps run on their own. Listing files, reading a git log or checking disk use needs no approval.
  • Everything else asks first. You see the exact command with Allow and Deny. Commands the safety rules flag always ask, with the reason.
  • Secrets stay out. Iris does not read .env, SSH keys or .pem files, and command output is redacted before the AI sees it.
  • Local only. The app listens on 127.0.0.1 and answers only to a private link. Chats are saved on your computer.
  • Rename it. newton config agent_name Theo changes the name Iris uses.

Iris works best with a capable model. Small local models can be slower and sometimes need a nudge to follow the step-by-step format. See the Iris page for a demo.

Commands

CommandWhat it does
newton ask <question>Streams an answer in your terminal. Pipe anything in (make 2>&1 | newton ask why did this fail) or attach files with -f.
newton chatA conversation with your shell attached. !cmd runs a command and shows Newton the output, /run executes the last code block.
newton fixLooks at your last command, re-runs it to see the real error, explains what went wrong and offers a fix. Destructive commands are never re-run.
newton agentOpens Iris, the chat agent, in your browser. Learn more.
newton commitReads your staged diff and writes a clear commit message. You approve it before anything is committed.
newton explain '…'A flag-by-flag breakdown of a command.
newton suggest -c "…"Print a suggestion and copy it to the clipboard. --json gives full JSON.
newton historyWhat you've asked recently.
newton doctorChecks your key, connection, shell integration, install and PATH.

newton fix needs the shell integration, which records your last command and exit status in a private file. For better plans, use a stronger model for heavy work: newton config smart_model claude-sonnet-5-5.

Config lives in ~/.config/newton/config.json. Cache and history are in ~/.cache/newton/, saved plans in ~/.local/share/newton/plans/. All three folders are owner-only.

Update and uninstall

newton update                      # finds the newest newton*.zip in ~/Downloads
newton update ~/Downloads/newton.zip
newton update https://…/newton.zip # https only

It shows the version change, asks first, builds and tests the new copy, and only then replaces the old one. A broken download can never replace a working install. Your settings, key and saved plans are untouched.

newton uninstall            # removes the program and Newton's lines in your shell config
newton uninstall --purge    # also deletes your settings, API key, history and saved plans

Other install options

sh install.sh --no-setup        # skip the guided setup
sh install.sh --no-path         # don't touch shell config files
sh install.sh --bin-dir ~/bin   # install somewhere else

Privacy

Each Tab request sends only your description plus a short environment summary: OS, shell, current folder path, project type, installed tool names, and top-level file names (which you can turn off). Tab suggestions never send file contents, environment variables, shell history or your previous commands.

  • Plan mode sends your goal, your answers to its questions and, if a step fails, the last lines of that step's output. Turn that off with newton config share_output false.
  • ask and chat send what you type or pipe in, and files you attach. Files that look like secrets (.env, keys, credentials) are refused.
  • fix sends your last command and its output. commit sends your staged diff.

Everything sent passes through a redactor first: API keys, tokens, passwords and private keys are replaced with placeholders. With Ollama nothing leaves your machine. Newton has no telemetry.

Troubleshooting

  • Tab does normal completion on my sentence. Start the line with #, or press Esc then N. That works in every terminal; Alt+N only works if your terminal sends Option as Meta, which macOS Terminal and iTerm don't by default. A line like newton find big files also works with Tab.
  • Tab stopped completing with oh-my-zsh or fzf-tab. Load Newton after other plugins (put the eval line last).
  • macOS bash. The built-in bash 3.2 is too old. Use zsh (the macOS default) or brew install bash.
  • newton: command not found after installing. Open a new terminal. If it persists, run ~/.local/bin/newton doctor.
  • Something else is shadowing Newton. newton doctor warns when your shell finds a different newton first, such as an old pip install. Remove the other copy.
  • Anything else: run newton doctor.
