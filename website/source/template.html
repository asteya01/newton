How Newton works

You know what you want to do. You just don't remember whether it's tar -xzvf or -zxvf, which find flag means bigger than, or how lsof takes a port.

1

Describe it

Write what you want in your prompt, the way you'd tell a colleague. No special syntax or quotes.

~ ❯ compress the logs folder
2

Press Tab

Newton tells sentences from commands. Sentences go to your AI. Commands like git ch still get normal Tab completion.

~ ❯ git ch⇥ → git checkout
3

Review, then Enter

The command replaces your words and nothing has run. Edit it, press Tab for alternatives, or Shift+Tab to get your words back.

~ ❯ tar -czf logs.tar.gz logs/

    Plan mode turns a goal into a checklist you can follow.

    For anything bigger than one command, Newton drafts the steps, shows you each one before it runs, and helps fix what breaks. All in the same terminal tab.

    • Preflight checkLists the programs the plan needs and whether they're installed, before step 1.
    • One key per stepEnter runs it. E edits it, S skips it, ? explains it, A asks a question, R revises the plan.
    • Failures get diagnosedNewton reads the error, proposes a fix and retries. Risky fixes still wait for you.
    • Undo and exportRoll finished steps back, newest first, or export the plan as a shell script.
    • Pause and resumeClose the tab any time. newton resume picks up at the same step.
    newton planset up a python project with pytest and git

    It knows your machine

    The same request becomes the right command for your system: BSD flags on macOS, GNU flags on Linux, and the loop syntax your shell actually speaks.

    macOS · zshsed -i '' 's/foo/bar/g' app.js for f in *.jpeg; do mv "$f" "${f%.jpeg}.jpg"; done
    Linux · fishsed -i 's/foo/bar/g' app.js for f in *.jpeg; mv $f (string replace .jpeg .jpg $f); end

    Your last command failed? Newton re-runs it, reads the real error and offers a fix.

    Ask and chat, in the terminal

    Pipe anything in and get an answer next to your work. !cmd in chat runs a command and shows Newton the output.

    ~ ❯ npm test 2>&1 | newton ask what broke The test imports ./utils, which was renamed to ./helpers in your last commit. Update line 3.

    Newton writes. You decide.

    Nothing runs until you press Enter, and the checks that flag dangerous commands live on your machine, not in the AI.

    • Nothing runs on its ownSuggestions land in your prompt. In plan mode every step is shown first, and destructive steps need a deliberate y, even in auto mode.
    • Local safety rules always applyThey flag rm -rf, sudo, force-pushes, curl | sh, disk writes and more, whatever the AI says.
    • Secrets are scrubbed firstAPI keys, tokens, passwords and private keys are replaced before anything is sent. Files that look like secrets are refused.
    • Fully offline if you want itWith Ollama, nothing leaves your computer. Newton has no telemetry.

    Install in about a minute.

    Newton is one file that needs Python 3.9 or newer. No pip, no virtual environment, no admin rights.

    1. Get newton.zip

      Public downloads open soon. Use the zip you were given for now.

    2. Unzip and run the installer

      In Terminal. macOS includes Python 3; it will offer to install developer tools if it's missing.

      cd ~/Downloads
unzip newton.zip
cd newton
sh install.sh

    Update or remove it

    newton update

    Updates are built and tested before they replace your copy. Uninstall only removes Newton's own lines from your shell config.

    Questions people ask first.

    Does Newton run commands for me?

    No. Tab puts the command in your prompt and stops. Plan mode runs a step only after you approve it, and destructive steps need an explicit y.

    Is it free?

    Newton is free and MIT licensed. Your AI provider may charge: Claude and OpenAI-compatible services bill for usage. Ollama runs models on your own computer at no cost.

    What does Newton send to the AI?

    For Tab suggestions: your request plus a short description of your setup (OS, shell, current folder, project type, installed tool names and top-level file names, which you can turn off). Never file contents, environment variables or shell history.

    Plan mode, ask, fix and commit send more, only when you use them: for example a failed step's output or your staged diff. Secrets are redacted first.

    Which shells and systems work?

    zsh, bash 4 or newer and fish, on macOS and Linux, including a Chromebook's Linux terminal. Windows works through WSL. macOS ships bash 3.2, so use zsh (the default) or install a newer bash.

    A local model gave me a wrong command.

    Small local models make more mistakes than Claude. Try a larger model such as qwen2.5:14b if your computer can run it, read the command before pressing Enter (Newton flags the dangerous ones), or paste it into newton explain for a flag-by-flag breakdown.

    Will it change my shell config?

    Only for shells you already use, and only inside a marked block. newton uninstall removes that block and any lines older versions added.
